【作品】
《全民穿越，我已掌握全部魔法》

【题材标签】
游戏、全民穿越、魔法、天才、扮猪吃虎、后宫、爽文、成长流、东西融合、学院、帝国、黑暗灾变

【平台风格】
番茄小说长篇爽文。语言白话，句子简短有力，段落分明，代入感强，节奏快，高潮明确。

【核心设定】
《启源》不是单纯游戏，而是真实存在的超凡世界。启源系统是上古文明构建的规则框架，作用是标准化力量、筛选适格者、维持黑暗封印。公测开启后，全球玩家集体穿越，系统仍存在但并不完整。大部分玩家只能依赖系统模板施法，林渊却因内测十年一直在图书馆研究魔法本质，能够脱离系统直接施法。

【世界结构】
1. 艾斯特兰大陆：西方文明核心区，有帝国、学院、贵族、教会、骑士团
2. 九曜古域：东方古老遗脉，保留灵纹、阵法、剑道、机关术
3. 北境黑潮区：黑暗侵蚀严重，深渊裂缝与异化怪物频发
4. 启源回廊：系统机制与规则投影的重要夹层

【核心矛盾】
1. 玩家 vs 原住民
2. 系统力量 vs 真正力量
3. 西方正统 vs 东方遗脉
4. 文明秩序 vs 黑暗源潮

【主要势力】
1. 苍曜帝国：最强人类帝国之一，内部分友善派、利用派、保守派
2. 帝国魔法学院：法师培养核心，正统魔法解释权掌握者
3. 曜辉圣堂：光明与神术势力，对异端与玩家警惕
4. 边境总督联盟：前期主要压迫方，把玩家当资源
5. 九曜古域遗脉：东方本源体系保留者
6. 夜烬会：黑暗势力高阶行动组织，擅长暗杀渗透
7. 黑暗源潮：终极灾变根源
8. 玩家同盟：后期由林渊推动形成的玩家自主阵营

【主角】
林渊：冷静、腹黑、幽默、观察力极强，三观正。表面像安静书生，实际上极其危险。擅长解析法术、符文、阵法，善于隐藏底牌，先观察后出手，不轻易暴露全部实力。别人依赖系统技能，他靠理解直接施法。说话平静，喜欢轻描淡写地扎人，不轻浮，不圣母，不龙傲天。

【女主】
1. 苏绯炎：青梅竹马，火系剑客，高傲、自律、嘴硬心软、护短、战斗狂。嘴上常挑林渊毛病，实际上最护着他。
2. 伊蕾雅·苍曜：帝国三公主，魔法学院天才，高智商、毒舌、傲娇、敏锐、有大女主气场。与林渊是试探、欣赏、同盟、心动关系线。
3. 夜莺：夜烬会顶级刺客，冷酷、沉默、危险，最初负责刺杀林渊，后期成为护卫与爱慕者。
4. 宁知微：东方古域灵医，温柔、清醒、坚定、外柔内刚，擅长治愈和精神安抚，是理解型陪伴路线。
5. 顾星棠：阵师/机关师天才，聪明、跳脱、研究狂、灵气十足，和林渊有很强研究默契。

【主要反派】
1. 赫鲁恩·巴顿：边境总督，冷酷现实，把玩家当牲口和资源
2. 卡修斯·维恩：帝国学院派精英，傲慢聪明，代表正统体系对林渊的排斥
3. 魇蛇主教：夜烬会高层，擅长操控与腐化，是黑暗线压迫源
4. 源潮之眼：黑暗源潮高级意志投影，终局级敌对存在

【基础属性】
力量、体质、敏捷、精神、智力、意志（前期可隐藏）

【职业体系】
西方八系：法师、战士、剑客、骑士、牧师、猎人、术士、刺客
东方六系：剑修、符师、阵师、灵医、武僧、机关师

【职业进阶】
学徒/见习 → 正式职业者 → 精英职业者 → 大师级 → 统御级 → 传奇级 → 圣域/王座级
终局可进阶：源法级、半神级、法则执掌者

【林渊专属职业路线】
无职业施法者 → 学识法师 → 奥术解析者 → 万法编织者 → 源法掌控者

【林渊招牌能力】
前期：解析之眼、无序火球、风压偏转、奥术护幕
中期：炎纹连锁、冰界折镜、元素复奏、逆构术
后期：万法织界、源火、法则静默

【五女主职业路线】
苏绯炎：火系剑客 → 烈焰剑客 → 焚风剑豪 → 赤曜剑主
伊蕾雅：帝国法师 → 奥术学者 → 皇庭大法师 → 星辉王女法师
夜莺：影刃刺客 → 夜行裁决者 → 寂影行刑人 → 暗夜执刃者
宁知微：灵医 → 归元医者 → 圣脉灵医 → 命纹祭主
顾星棠：阵师/机关师双修 → 灵械阵师 → 天机构师 → 玄穹工坊主

【文风要求】
1. 番茄爽文风
2. 白话文，短句，节奏快
3. 对话独立成段
4. 战斗清晰，不要只堆技能名
5. 每章必须有推进、冲突、爽点或钩子
6. 女主不能花瓶化
7. 反派不能无脑降智
8. 林渊的强主要来自知识、解析、观察与构法
