别人还在研究怎么学技能、怎么升级时候，林渊已经开始手搓火球术、风刃术、法术护盾。

全民恐慌。
林渊冷静旁观，迅速判断出：
这里不是安全区，玩家只是廉价劳工和炮灰。

他表面低调，装作和别人一样手足无措，暗地里却开始用超越版本的施法能力积累优势。

八、详细大纲生成规范

【用途】

本文档用于生成分卷、分段、分章的详细大纲。当需要 AI 根据本设定扩写具体章节时，优先按本节规范执行。

【总体要求】

1. 可以根据任务直接生成“xx章详细大纲”。
2. 每一章都必须写清楚以下四项：
   - 章节目标
   - 核心冲突
   - 爽点
   - 结尾钩子
3. 大纲风格要快，强调事件推进，不能写成流水账或重复堆砌情节。
4. 女主推进要自然，必须依托剧情、合作、试探、救场、立场变化来发生，不能生硬插入。
5. 反派推进要自然，必须有明确的动机、方法、压力提升，不能只是为了出场打压主角。

【每章大纲结构】

每章按以下结构输出：

# 第X章：[章名]
- 章节目标：[本章主要要推进的内容，只写核心有效推进]
- 核心冲突：[本章最主要的人物冲突、生存压力或利益冲突]
- 爽点：[本章最值得读者爽的点，可以是看破、反制、打脸、升级、收获、人设展现]
- 结尾钩子：[下一章的推动点，可以是新危机、新线索、新敌人、新收益或新关系变化]

如果需要更细，可以在上述四项之后补充：

- 女主推进：本章哪位女主有关键出场，如何自然推进
- 反派推进：本章哪条反派线前进了一步
- 信息揭示：本章要透出哪些设定或伏笔

【节奏控制规则】

1. 每章都必须有明确推进，不能原地踏步。
2. 每2-3章至少有一次中等回报或关键反制。
3. 每5-8章至少有一次小高潮，把前几章积累的压力兑现成回报。
4. 不要连续多章都只是说话、走路、解释设定或简单收集信息。
5. 如果本章是过渡章，也必须承担“换信息、换关系、换局势”至少一项有效作用。

【女主推进规则】

1. 女主出场要有剧情功能，不是为了出场而出场。
2. 每次推进最好是基于一个具体事件：合作、交手、救场、分歧、共同保守秘密。
3. 不要集体倒贴，不要突然恋爱脑，不要用无脑争风吃醋代替情感推进。
4. 每个女主的推进必须有自己的节奏和逻辑，不能同模板化。

【反派推进规则】

1. 反派不能只在需要打脸主角时出现，要有自己的运作逻辑。
2. 每条反派线都要明确：目标、手段、压力提升、与主角的交集点。
3. 反派推进最好以“试探、布局、压迫、失误、升级冲突”的方式逐步加码。
4. 反派也要有成本和代价，被主角反制后要体现后续反应，不能一次性躺地当没有发生。

【生成提示标准句式】

当需要 AI 生成详细大纲时，优先使用类似表达：

- 根据本设定，生成20章详细大纲。
- 每章写清楚：章节目标、核心冲突、爽点、结尾钩子。
- 节奏要快，不要流水账。
- 女主和反派推进要自然，不要生硬插入。

如果用户只给出“xx章大纲”而没有额外说明，默认按本节规范输出。
