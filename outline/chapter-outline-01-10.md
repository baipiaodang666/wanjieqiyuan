# 《全民穿越，我已掌握全部魔法》1-10章章纲

前十章阶段目标：

- 完成“3章3回报”，开局就把系统残缺、真实死亡、原住民压榨三件事砸实。
- 第7章前给出林渊第一次明确实战施法。
- 第10章完成第一次“规则反杀 / 契约打脸”。
- 让苏绯炎完成“质疑 -> 惊讶 -> 默认跟随”的关系推进。

## 第1章 公测当天，系统先废了

- 章节目标：完成全民穿越落地，第一时间砸出“系统残缺”和“这里会死人”的开局压迫。
- 核心冲突：所有玩家都还在找退出键和技能栏，现实却已经不给他们试错时间。
- 本章即时回报：林渊比所有人更早察觉系统只剩外壳，并在广场石柱上感知到第一缕真实火元素，确认自己学过的知识没有废掉。
- 爽点：玩家集体慌乱时，林渊没有跟着乱找面板，而是直接判断问题不在“没技能”，而在“系统坏了”。
- 结尾钩子：镇执政官哈德当众射杀第一个冲撞秩序的玩家，广场彻底死寂。
- 女主推进：苏绯炎在混乱里第一时间靠向林渊，建立“嘴上不服，出事先找他”的关系底色。
- 反派推进：哈德出场，第一次把玩家定义成“可登记、可管控、可分配”的对象。

## 第2章 这根本不是游戏

- 章节目标：把“真实死亡”彻底落地，让读者明确知道这不是游戏穿越，而是残酷求生。
- 核心冲突：玩家还想讲公测规则，原住民却直接用军管方式接收这批“新资源”。
- 本章即时回报：林渊通过守卫站位、箭塔角度和登记台流程，提前看出晨露镇早就准备好了一整套收容方案，保住自己和苏绯炎没有在混乱里被分开。
- 爽点：别人还在吵“官方补偿”，林渊已经看懂广场不是新手点，而是临时收容场。
- 结尾钩子：军务官格林拿出名册，开始把玩家按“劳力、炮灰、试用战斗员”三类分流。
- 女主推进：苏绯炎第一次明显压住脾气，选择先听林渊判断，而不是直接拔剑顶上去。
- 反派推进：格林登场，负责后续任务压榨和制度性收割。

## 第3章 玩家不是勇者，是耗材

- 章节目标：把原住民对玩家的压榨从“武力威慑”推进到“制度分配”。
- 核心冲突：玩家还想争体面和选择权，镇方却已经按消耗品标准给他们贴标签。
- 本章即时回报：林渊利用登记漏洞和名单顺序，把自己和苏绯炎调进采集巡查队，拿到相对更自由、也更容易接触野外情报的位置，完成前三章第一次明确小赢。
- 爽点：别人争的是看起来最轻松的差事，林渊抢的是最容易活下去、最容易看见真相的位置。
- 结尾钩子：登记台上的一枚特殊印记映入林渊眼中，那纹路和他在图书馆见过的古符文高度相似。
- 女主推进：苏绯炎第一次意识到，林渊不是在躲事，而是在主动挑最有利的路。
- 反派推进：格林开始记住林渊这个过分冷静的玩家，起了试探心思。

## 第4章 会用技能，不等于会战斗

- 章节目标：切开“会玩游戏”和“能在真实世界活下去”的区别，让林渊第一次在人前显出理论压制力。
- 核心冲突：老玩家还想靠内测经验摆资历，原住民教官却把他们当笑话。
- 本章即时回报：林渊一句话点出苏绯炎的发力断点，让她临场修正出剑，一剑劈裂训练木桩，立刻打出肉眼可见的提升。
- 爽点：别人挨完教训才知道自己弱，林渊站在旁边看一眼就能说出问题出在哪。
- 结尾钩子：格林第一次正眼看向林渊，问他到底学过法术理论，还是学过军阵。
- 女主推进：苏绯炎第一次真切意识到，林渊那些“看书看出来的东西”可能比她手里的剑更危险。
- 反派推进：格林开始怀疑林渊不是普通玩家，而是值得重点观察的异数。

## 第5章 新手村外，没有安全区

- 章节目标：推进第一次出镇任务，把“新手村不是保护区”狠狠干出来。
- 核心冲突：镇方说这是低风险采集，实际却在用信息差和补给压缩拿玩家探路。
- 本章即时回报：林渊仅靠风向、脚印、折枝和泥地痕迹，就提前带队绕开第一处怪物伏击带，直接救下本队一命。
- 爽点：几个不信邪的老玩家当面嘲笑林渊胆小，结果转头就冲进真正的危险区。
- 结尾钩子：林中深处骤然传来凄厉惨叫，那支不听劝的队伍出事了。
- 女主推进：苏绯炎第一次不再和林渊抬杠，而是自然顺着他的节奏推进队伍。
- 反派推进：格林借任务试探玩家损耗率，故意隐瞒野外真实风险。

## 第6章 今天开始，真的会死

- 章节目标：做出前十章第一轮血腥冲击，让玩家和读者都彻底接受“这里真会死人”。
- 核心冲突：野外遭遇不是试炼，而是猎杀；原住民把玩家送出来，本来就没打算全带回去。
- 本章即时回报：别人还在乱跑乱叫时，林渊已经看出裂爪狼的包围轨迹，强行卡出唯一撤退路线，带着一批人硬生生冲出包围圈。
- 爽点：玩家第一次发现，真到生死一线时，系统面板没办法替他们判断，林渊却能。
- 结尾钩子：撤退最后一刻，苏绯炎为了断后被裂爪狼一爪拍中后背，整个人扑倒在地。
- 女主推进：苏绯炎第一次真正落入“没有林渊就会死”的绝境。
- 反派推进：原住民远远观望、只记损耗不救人，这份恶意被彻底坐实。

## 第7章 没有技能栏的火球

- 章节目标：打出前十章第一个真正硬爽点，完成林渊第一次明确实战施法。
- 核心冲突：苏绯炎重伤，狼群逼近，所有常规手段都已经来不及。
- 本章即时回报：林渊靠记忆中的基础回路和元素引导，在没有技能栏的情况下强行构出一枚简化火球，精准轰爆头狼眼窝，当场救下苏绯炎和身边几名幸存者。
- 爽点：所有人都看见了法术，却没人能在林渊面板上找到对应技能，这一击直接把“别人靠系统，林渊靠理解”的卖点打实。
- 结尾钩子：格林手下的记录员远远看见这一幕，脸色发白地吐出一句：“他没用技能。”
- 女主推进：苏绯炎第一次亲眼看到林渊“看书看出来的魔法”，世界观被狠狠干碎。
- 反派推进：林渊被贴上“异常施法者”的第一枚暗标签，危险等级陡然上升。

## 第8章 他和我们不是一回事

- 章节目标：把第7章的硬爽点转成主角势，让一小批玩家开始真正围着林渊转。
- 核心冲突：有人想抱大腿，有人怀疑林渊故意藏私，有人不愿承认自己和他差太远。
- 本章即时回报：林渊从头狼尸体里挖出一枚异常黑骨片，确认这次狼袭不是普通意外，而是被某种污染力量催化过的袭击，拿到前十章第一条关键真相。
- 爽点：面对质疑，林渊不解释自己“为什么会”，而是直接把刚才每个人死在哪里、错在哪里、为什么只有他能成，全部一句句点穿。
- 结尾钩子：回镇路上，格林已经带人等在镇门口，目光第一个落在林渊身上。
- 女主推进：苏绯炎从“我知道你不简单”升级到“你和所有人都不是一个层次”的震动，开始默认站林渊这边。
- 反派推进：格林从暗中观察转向第一次正面试探，准备把林渊拉进自己的规则笼子里。

## 第9章 任务结算，不结人命

- 章节目标：把冲突从野外生死拉回镇内规则，做前十章第二轮中型回报。
- 核心冲突：死了那么多人，镇方却只按采集物资结算，不提责任，也不提补偿。
- 本章即时回报：格林本想用任务文书堵住所有人的嘴，结果被林渊当众拆穿免责条款和文字陷阱，逼得镇方补发伤药、食物和一晚休整时间，幸存玩家第一次拿到实打实的利益。
- 爽点：原住民想用规矩压人，林渊反过来用规矩把他们顶了回去。
- 结尾钩子：格林表面退让，反手宣布组建“夜巡清理队”，并点名林渊和苏绯炎必须参加。
- 女主推进：苏绯炎第一次在人前毫不掩饰地站到林渊身侧，关系从默契迈向公开并肩。
- 反派推进：格林由“观察”正式升级为“针对”，开始准备合理合法地弄死林渊。

## 第10章 契约里的刀

- 章节目标：完成前十章阶段小高潮，把“原住民不只靠武力压人，更靠规则吃人”彻底坐实。
- 核心冲突：不签契约没饭吃，签契约等于卖命；玩家被一步步逼进绝境。
- 本章即时回报：林渊在众目睽睽之下拆出契约里的隐藏惩罚条款、死亡转嫁机制和终身劳役后门，逼得格林当场改契约，幸存玩家第一次拿回部分选择权。
- 爽点：原本对林渊有意见的几个玩家，这次全都闭了嘴，第一次默认听他安排，林渊在玩家群体里真正立名。
- 结尾钩子：夜巡出发前夜，林渊在分到的旧装备夹层里，摸出一张画着陌生符纹的残破纸片。
- 女主推进：苏绯炎对林渊的佩服第一次明显压过嘴硬，完成“质疑 -> 惊讶 -> 默认跟随”的前十章阶段变化。
- 反派推进：格林彻底恨上林渊，准备借夜巡任务公开清理这个刺头；更高层的秘密线也通过残纸第一次露头。

前十章阶段校验：

- 第1-3章完成“系统残缺 + 真实死亡 + 玩家耗材化”三连压迫。
- 第4-6章切开“会玩游戏”和“能活下去”的差别，并完成第一轮野外生死打击。
- 第7章兑现第一次明确实战施法。
- 第9-10章完成第一次规则博弈胜利和契约打脸。
- 苏绯炎关系线完成“质疑 -> 震动 -> 并肩 -> 默认跟随”。
